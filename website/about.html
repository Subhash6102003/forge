Guiding Standards

Core Engineering Principles

01 • Minimal Diff, Zero Bloat

YAGNI & Surgical Edits

Inspired by seasoned engineering discipline (-53% code). Never write hand-rolled utilities for solved problems. Touch only what the brief demands; leave existing code pristine.

02 • Contract-Driven Delegation

Formal Briefs & Reports

Eliminate conversational hallucination through structured TASK BRIEF and TASK REPORT contracts with hard quality gates.

03 • Empirical Verification

Measured vs Estimated

Never invent metrics or benchmarks. Every latency number is labeled MEASURED with reproduction method, or ESTIMATED with explicit assumptions.
