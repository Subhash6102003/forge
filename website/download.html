Workstation Requirements

Hardware & Local Model Runtime Guide

01

Recommended Hardware

RAM / Unified Memory

Minimum 8 GB RAM for 3B/7B quantized models (Q4). Recommended 16 GB - 32 GB for concurrent multi-agent debate turns.

GPU Acceleration

NVIDIA RTX 3060+ (8 GB+ VRAM with CUDA) or Apple Silicon M-Series (Metal acceleration). CPU inference supported via AVX2/AVX-512.

Disk Storage

15 GB+ free SSD space for storing local model GGUF weights and Monaco editor workspaces.

02

Ollama Setup (2 Minutes)

  1. Download Ollama from ollama.com.
  2. Run the local service: 
    ollama serve
  3. Pull recommended coding models: 
    ollama run qwen2.5-coder:7b
ollama run deepseek-coder:6.7b
  4. Launch Forge. Forge automatically connects to http://localhost:11434 without configuration.
