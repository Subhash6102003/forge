# Algorithmic Art Engine

## Philosophy
Algorithmic art bridges code and generative aesthetics. Every visual piece generated inside Forge must be:
1. **Deterministic & Seeded**: Using integer seed values `randomSeed(seed)` and `noiseSeed(seed)` to guarantee that identical seeds yield identical artwork across machines and render passes.
2. **Interactive Parametrization**: Sliders for noise scale, particle count, flow speed, and color palettes.
3. **Palette Cohesion**: Leveraging Forge brand colors (`#D97757`, `#6A9BCC`, `#788C5D`, `#FAF9F5`, `#141413`) alongside algorithmic harmonies.
4. **Export Ready**: 1-click high-resolution PNG / SVG export for project assets and splash artwork.
