# Forge Brand Guidelines

## Brand Palette
- **Primary Neutrals**:
  - Dark: `#141413`
  - Light: `#FAF9F5`
  - Mid Gray: `#B0AEA5`
  - Light Gray: `#E8E6DC`
- **Signature Accents**:
  - Terracotta Orange: `#D97757`
  - Mineral Blue: `#6A9BCC`
  - Olive Sage Green: `#788C5D`

## Typography Hierarchy
- Headings & Hero Elements: **Poppins** (Semi-bold / Bold, geometric precision, modern clarity)
- Body & Long-form Narrative: **Lora** (Editorial elegance, readability)
- Code & Monospaced UI: **JetBrains Mono** / System Mono

## Precedence Rule
- **Inside IDE Chrome**: Subhash UI/UX calm enterprise rules win. High-contrast editor tokens, muted tab borders, zero distraction.
- **Brand Skin Application**: Home Dashboard, splash screens, welcome banners, documentation headers, and Art Studio exports.
